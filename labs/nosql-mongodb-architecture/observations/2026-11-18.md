# MongoDB 계층·저장 경계 관찰 · 2026-11-18

## 실행 환경

- Docker Server: `29.7.2`
- Docker Desktop VM Kernel: `7.0.12-linuxkit` (`arm64`)
- 성공 Runtime: MongoDB `7.0.41`, Node.js Driver `7.9.0`, Node.js `24.11.1`
- MongoDB Image digest: `sha256:52ba5332636758f2375228827d5cf7460e25c02063ba19c243e5d262cf4e7924`
- MongoDB `gitVersion`: `ce905e55f7dd2a19fcb437f709682c442abb12c6`

## 확인한 경계

1. JavaScript 주문 Object를 Driver가 BSON `237 bytes`로 직렬화했다. BSON의
   첫 4 bytes를 little-endian integer로 읽은 값도 `237`이었다.
2. Driver command monitoring에서 `create`, `createIndexes`, `insert`, `update`,
   `commitTransaction`, `find` Command가 시작되는 것을 확인했다.
3. `{customerId: 1, status: 1}` 복합 Index `customer_status`를 만들고 Query했다.
   `explain("executionStats")`는 이 Index를 사용했으며 Key 1개와 Document 1개를
   검사해 1개를 반환했다.
4. 단일 Node Replica Set `rs0`에서 Alice 잔액을 15,000 줄이고 Bob 잔액을
   15,000 늘리는 두 Update를 `txnNumber: 3`으로 묶었다. Driver가
   `commitTransaction`을 전송했고 최종 잔액은 85,000과 45,000이었다.
5. Server는 Storage Engine을 `wiredTiger`, persistent와 snapshot read concern
   지원을 `true`로 보고했다.
6. WiredTiger Collection creation string에서 `format=btree`, allocation unit
   `4KB`, internal page max `4KB`, leaf page max `32KB`, block compressor `snappy`를
   관찰했다. 이 값은 이 Version과 기본 설정의 관찰값이다.
7. `/data/db`에서 Collection과 Index별 `.wt` 파일, `WiredTiger.wt`,
   `WiredTigerHS.wt`, `_mdb_catalog.wt`, `journal/WiredTigerLog.0000000001`을
   확인했다.

## Version blocker

처음 선택한 `mongo:8.0.30-noble`, 이어 확인한 `mongo:8.0.38-noble`은 모두
Docker VM Kernel `7.0.12-linuxkit`을 `SERVER-121912` 영향 범위로 판단해 시작을
거부했다.

```text
MongoDB cannot start: Linux kernel versions 6.19.0 through 7.0.13
have a known incompatibility with this version of MongoDB.
```

그래서 Kernel 제한에 걸리지 않으면서 BSON, Index, Multi-document Transaction,
WiredTiger와 Journal을 모두 재현할 수 있는 `7.0.41`로 실제 검증 범위를 낮췄다.
8.0 전용 Query 동작은 이 관찰로 검증했다고 표시하지 않는다.

## 검증하지 않은 것

- Multi-node failover와 고가용성
- Sharded Cluster의 routing과 cross-shard transaction
- 인증·TLS가 포함된 운영 구성
- Large dataset의 압축률·cache eviction·성능
- MongoDB 8.0 전용 Query Planner/Execution 동작
